1. About this app / 关于应用

ASui Ide is an independent Android development tool provided under the developer name m4coding. Contact: m4coding@qq.com. This policy describes the current build prepared on 2026-11-18. / ASui Ide 是以 m4coding 开发者名称提供的独立 Android 开发工具，联系邮箱 m4coding@qq.com。

2. Projects and local storage / 项目与本地存储

Projects, editor preferences, source history, build output and signing identities are stored on your device. The SDK is bundled with the app. Studio does not operate product accounts, cloud synchronization or a cloud build service in this version. Studio disables Android cloud backup and excludes app-private data from device transfer. Export important work and signing backups yourself. Files or backups you save outside the app are managed separately and are not deleted by uninstalling Studio. / 项目、源码历史、构建结果及签名身份保存在设备上；SDK 随安装包提供。本版本不提供产品账号、云同步或云构建服务。Studio 关闭 Android 云备份，并将应用私有数据排除在设备迁移之外。请自行导出重要项目与签名备份。卸载应用不会删除您另行保存的导出文件和签名备份。

3. Advertising / 广告

Studio uses Google AdMob and Google User Messaging Platform. The Google Mobile Ads SDK may collect and share IP addresses (which can indicate approximate location), device identifiers, ad interactions and diagnostic information for advertising, measurement and fraud prevention. Studio does not attach source code, project contents, Git credentials or signing passwords to ad requests. Consent and privacy options are presented where required. A network connection is required to use Studio. Google policy: Google Privacy Policy; SDK disclosure: Google Mobile Ads data disclosure. / 应用使用 Google AdMob 广告及 UMP 同意管理。广告 SDK 可能收集和共享 IP 地址（可推断大致位置）、设备标识符、广告互动和诊断信息，用于广告、效果衡量和防欺诈。应用不将源码、项目内容、Git 凭据或签名密码附加到广告请求中；在适用地区提供同意与隐私选项。使用应用需要联网。

4. Actions you choose / 您主动选择的网络操作

When you use remote Git, the chosen repository provider receives repository traffic, authentication information and the commits/files you send. The provider applies its own privacy and retention policies. A project can access approved HTTPS domains through the runtime broker after you review its declared capabilities. The remote service receives the data that project code sends. / 使用远程 Git 时，您选择的仓库服务会收到仓库请求、验证信息及您推送的文件和提交，并适用该服务的隐私规则。项目经过能力与域名审核后可向获准的 HTTPS 服务发送项目代码指定的数据。

5. Feedback and reviews / 反馈与评价

Feedback opens your email app. You decide what to write, attach and send to m4coding@qq.com. The app does not automatically send an email or attach diagnostics. If you contact us, we receive your email address and the content you choose to send and use it to respond to your request. Reviews open Google Play; Google handles any review you submit. / 反馈功能打开邮件应用，由您决定撰写、附加和发送的内容；应用不会自动发送邮件或添加诊断附件。您主动联系后，我们会收到邮件地址和您发送的内容，用于处理该请求。应用评价由 Google Play 接收与处理。

6. Control and deletion / 控制与删除

Use Studio’s project and data controls to remove local content. Android app settings can clear application data. Keep copies of any signing identities needed for future app updates. Manage Git data with the chosen repository provider and ad choices through available privacy options and Android settings. For feedback correspondence or privacy requests, email m4coding@qq.com. We do not set retention periods for third-party providers; consult their policies. / 可通过应用内项目与数据控制或 Android 应用设置清理本地数据；请自行保留后续更新所需的签名身份。远程 Git 数据由仓库服务管理；广告选项可通过适用隐私入口与系统设置控制。如需处理反馈邮件或隐私请求，请发送邮件至 m4coding@qq.com。第三方数据保留规则以其政策为准。

7. Security and changes / 安全与变更

Studio uses HTTPS for supported remote Git and brokered project network requests. No storage or transmission method can guarantee absolute security. This policy will be updated when the app’s data practices change. / 支持的远程 Git 和项目代理网络请求使用 HTTPS；任何存储或传输方式均不能保证绝对安全。数据处理方式发生变化时将更新此政策。
